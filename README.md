# DNIPRO article claim graphs

Interactive comparisons of news coverage for 15 selected days.

[Open the website](https://cherrysowmya.github.io/dnipro-claim-graphs/)

The landing page is `index.html`. Each dated folder contains its interactive graph and downloadable claim data. The graphs include attributed claims, supporting passages and proposed relationships for human review.

GitHub Pages serves the root of the `main` branch. The site uses static HTML and JSON with no build step.
